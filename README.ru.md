# USBview HS

[English](README.md) · **Русский**

USBview HS — инспектор USB для macOS. Он показывает, через какие порты и хабы подключены устройства, и позволяет переподключить устройство прямо из дерева USB.

В приложении есть окно на SwiftUI и консольная утилита на Haskell. Оба показывают одно и то же дерево из реестра ввода-вывода macOS (IORegistry). Язык интерфейса по умолчанию — русский. Переключиться на английский можно в настройках.

## Установка на Mac с Apple Silicon

Для macOS 15 и новее скачайте архив с окончанием `macos-arm64.zip` из [релизов на GitHub](https://github.com/poise52/USBview-HS/releases), распакуйте его и перенесите `USBviewHS.app` в папку «Программы». Релизные сборки используют подпись ad hoc и не проходят нотаризацию Apple.

## Сборка и запуск

Для сборки нужны macOS 15 или новее, Xcode с macOS SDK и компилятором Swift 6, GHC, cabal-install и Make. Из корня репозитория выполните

```sh
make run
```

Команда соберёт и откроет `build/USBviewHS.app`. Исполняемый файл на Haskell входит в пакет приложения. Сборка рассчитана на архитектуру текущего Mac и подписывается локальной ad-hoc подписью. Для сборки без запуска используйте `make build`. Если Xcode установлен в нестандартном месте, укажите путь к его каталогу `Contents/Developer` в переменной `DEVELOPER_DIR`.

## Строка меню и настройки

Нажмите на значок USB-разъёма в строке меню macOS, чтобы увидеть подключённые устройства. Нажмите на название для перехода в карточку или на кнопку переподключения рядом. Перед сбросом устройства или хаба приложение попросит подтверждение. Чтобы оставить панель поверх других окон, нажмите **Мини-окно USB** внизу боковой панели. Оно открывается в левом верхнем углу, и его можно передвинуть.

**Настройки** открываются кнопкой внизу боковой панели, шестерёнкой в мини-окне или сочетанием **⌘,**, когда USBview HS активно. Можно выбрать русский или английский язык, скрыть значок в строке меню и установить интервал автообновления в 1, 2, 5 или 10 секунд. Настройки сохраняются между запусками.

## Переподключение устройства или хаба

Выберите устройство в боковой панели или в обзоре, нажмите **Переподключить…** и подтвердите действие. USBview HS запросит у macOS сброс и сообщит, появилось ли устройство снова на том же порту.

Если устройство исчезло из дерева, можно сбросить хаб, к которому оно подключено. При этом ненадолго отключатся все устройства на этой ветке. Перед сбросом хаба извлеките в Finder все смонтированные тома на этой ветке.

## Что видно в дереве

| Что выбрать | Какие сведения доступны |
| --- | --- |
| Контроллер или хаб | Подключённые устройства, вложенные хабы и свободные порты. Линии USB 2 и USB 3 одного разъёма объединяются, если в реестре есть связь между ними. |
| Порт | Лимиты тока при работе и во сне, счётчики ошибок по каждой линии и доступные сведения о транспортах USB-C. |
| Устройство | VID и PID, серийный номер, согласованная скорость, активная конфигурация, интерфейсы и драйверы. Кнопка **Дескрипторы конфигураций…** читает конфигурации, альтернативные настройки интерфейсов и конечные точки. |
| Ethernet-адаптер или накопитель | Для адаптера — BSD-имя интерфейса, MAC-адрес, MTU и состояние соединения. Для накопителя — имена носителей и разделов, размеры и доступность записи. Набор полей зависит от драйвера. |

Поиск работает по названию, производителю и `VID:PID`. Нажмите **⌘R**, чтобы обновить снимок вручную, или включите **Автообновление** для периодического опроса (по умолчанию раз в две секунды). В журнале хранятся последние 200 замеченных подключений и отключений. Если устройство успело подключиться и отключиться между снимками, событие может не попасть в журнал.

## Работа в терминале

| Команда | Результат |
| --- | --- |
| `make tree` | Снимок USB в виде дерева |
| `make dump > topology.json` | Дерево и свойства в JSON, включая доступные серийные номера |
| `make watch` | Начальное дерево, затем подключения и отключения с отметками времени. Для выхода нажмите Ctrl+C |
| `make descriptors` | Дескрипторы конфигураций подключённых устройств и хабов |

Чтобы посмотреть отдельную категорию, запустите исполняемый файл внутри собранного приложения. Эти команды работают без открытия окна.

```sh
app=./build/USBviewHS.app/Contents/MacOS/USBviewHS
"$app" --network
"$app" --storage
"$app" --details
```

## Разработка

В [манифесте Cabal](usbview-hs.cabal) описаны консольная утилита, её зависимости и тесты топологии. [Код на Haskell](engine/) читает реестр через IOKit и строит дерево. [Код на Swift](app/) показывает снимки, читает дескрипторы через IOUSBLib и переподключает устройства вызовом `IOUSBHostDevice.reset()`.

```sh
cabal build
cabal test
cabal run usbview-hs -- --dump-tree
cabal repl exe:usbview-hs
```

Для проверки всего проекта выполните `make test`. Команда запускает тесты топологии и Swift-тесты, проверяет декодирование живого снимка из собранного приложения и подпись пакета.

Чтобы опубликовать релиз, отправьте на GitHub тег вида `v1.2.3`. GitHub Actions возьмёт версию приложения из тега, выполнит `make test` и опубликует ZIP для Apple Silicon вместе с контрольной суммой SHA-256.
